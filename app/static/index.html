Classify single or batched inputs against competing candidate labels with Amber 150M (fast English-primary) or BGE-M3 Zero-Shot v2.0 (multilingual / Korean, up to 8,192 tokens) via a standard Jina AI / OpenAI-style /v1 API.

POST/v1/classifyBearer or X-API-Key authentication

01 / input

Send a string, a {"text": ...} object, or a batch of 1–64 items up to 8,000 chars each by default (configurable up to 16,000).

02 / labels

Pass 2–16 competing labels as a list of names or a dictionary with concise descriptions.

03 / data

Receive ordered predictions sorted by score plus exact prompt_tokens and total_tokens usage.

Your first request

Set BASE_URL to your service URL and API_KEY to your issued chk_… API key. Pass it via Authorization: Bearer $API_KEY or X-API-Key: $API_KEY. You can also send requests using the Authorize button in the docs.

curl "$BASE_URL/v1/classify" \
  -H "Authorization: Bearer $API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "amber-150m",
    "input": [
      "I was charged twice for the same order.",
      {"text": "The checkout page returns a 502 error."}
    ],
    "task": "department",
    "prompt": "Which team should handle this request?",
    "labels": {
      "billing": "Charges, refunds, and invoices",
      "technical": "Website, login, or technical outages"
    }
  }'

Returns object: "list", canonical model, ordered data entries with prediction, score, and descending predictions, plus usage token counts.

Competing candidates, clear context

Pass a string, a {"text": ...} object, or a batch array in input, and define competing candidate labels in labels. For yes/no or safety gates, provide two meaningful competing options rather than a single statement.

{
  "model": "amber-150m",
  "input": {"text": {"command": "git status -s && pytest -q", "cwd": "/workspace/app"}},
  "task": "command_safety",
  "prompt": "Classify the risk category of running this command in a developer workspace.",
  "labels": {
    "read_or_test": "Inspects status or runs local tests without destructive side effects",
    "state_mutation": "Edits source files, installs packages, or commits changes",
    "destructive": "Deletes data, resets git history, or modifies system configuration"
  }
}
  • Choose "model": "amber-150m" (default, English-primary, up to 7,999 prepared tokens) for low-latency routing, or "model": "bge-m3-zeroshot-v2.0" for multilingual / Korean zero-shot NLI classification (up to 8,192 tokens per text/hypothesis pair).
  • Pass bare label lists (e.g. ["negative", "neutral", "positive"]) when label names are self-explanatory.
  • Add concise label descriptions and an optional prompt when domain boundaries need disambiguation.
  • Oversized inputs return an OpenAI-style error envelope instead of truncating silently; total request bodies are capped at 256 KiB.
